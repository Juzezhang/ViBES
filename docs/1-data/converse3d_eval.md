# Converse3D Evaluation Set (Q2M)

The question-to-motion benchmark behind the paper's Table 2 (see
[`4-evaluation.md`](../4-evaluation.md)). Each entry pairs a question with the motion segment
that answers it:

| Split | BEAT2 (conversational) | AMASS (motion-descriptive) | Total |
|---|---|---|---|
| train | 15,187 | 16,558 | 31,745 |
| val | 738 | 1,036 | 1,774 |
| test | 1,793 | 3,128 | 4,921 |

- **Questions:** generated by us with GPT-4o-mini.
- **Motion:** comes from BEAT2 and AMASS, which we cannot redistribute.
- **What we release:** the split files, from which you cut the segments out of your own copies.
  The segments are identical to the ones we evaluated on.
- **Which splits you need:** `test` is enough to evaluate a model. `train` and `val` are only
  needed to retrain the Q2M evaluator.

## Step 1 — Download the split files

```bash
huggingface-cli download JuzeZhang/Converse3D --repo-type dataset \
    --include "q2m_eval/*" --local-dir <DOWNLOAD_DIR>
# -> <DOWNLOAD_DIR>/q2m_eval/{train,val,test}.jsonl
```

Each line has these fields:

- `segment_id`, `source` (`beat2` / `amass`), `source_id`, `split`, `speaker_id`;
- the question;
- the segment boundaries `start_frame_25fps` / `end_frame_25fps`, at 25 fps.

## Step 2 — Prepare the two motion sources

| Source | What you need | How |
|---|---|---|
| BEAT2 | `<BEAT2_ROOT>/smplxflame_25/` | [`beat2.md`](beat2.md) Steps 1 and 3. The mirror in Step 2 is not used here |
| AMASS | `<AMASS_TALKING_ROOT>/amass_data_align_25_audios_rotation/` | [`amass.md`](amass.md) Steps 1–5. Step 5 converts all three HumanML3D splits by default, and the evaluation set uses clips from all of them |

## Step 3 — Build the motion segments

```bash
python preprocess/build_converse3d_eval.py \
    --jsonl_dir          <DOWNLOAD_DIR>/q2m_eval \
    --beat2_root         <BEAT2_ROOT> \
    --amass_talking_root <AMASS_TALKING_ROOT> \
    --output_root        <CONVERSE3D_EVAL_ROOT> \
    --splits test        # add train val to retrain the evaluator
```

This writes `<CONVERSE3D_EVAL_ROOT>/{split}.jsonl` and
`<CONVERSE3D_EVAL_ROOT>/motion_segments/{split}/<segment_id>.npz`:

- **BEAT2 segments** are frames `[start_frame_25fps, end_frame_25fps)` of the 25 fps sequence.
  A few segments end past the last motion frame; they stop at the end of the motion.
- **AMASS entries** are whole clips. The `M`-prefixed ids are the mirrored clips.

## Step 4 — Check the result

Score the ground-truth motion with the Q2M evaluator (`model_files/pretrained_cpt/evaluator/`, from
the checkpoint folder in [`0-overview.md`](../0-overview.md)). You should get the numbers from
[`4-evaluation.md`](../4-evaluation.md#gt-baseline) (balanced R-Precision Top-1 0.7122, MM Dist
2.3415, Diversity 11.0476):

```bash
python scripts/eval_question_motion_stratified.py --data-root <CONVERSE3D_EVAL_ROOT>
```

Then evaluate a model with `scripts/eval_vibes_body_q2m.py --data_root <CONVERSE3D_EVAL_ROOT>`.
